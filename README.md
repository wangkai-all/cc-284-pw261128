# 去标识数据发布审查台（De-identification Release Review Console）

面向"同一接收方、多个时间段去标识数据反复发布"场景的审查工具：核对历史发布记录与
候选数据，**具体展示哪些 QI 组合因新增文件缩小了接收方掌握的群体**，支持抑制、分桶、
拒发三种处置并比较信息损失，维护只追加的发布账本与下载中心。

> ⚠️ 本台的群体大小、缩小信号与损失指标都是**描述性度量**。
> **任何简单阈值（包括本台的小群体审查线）都不能保证绝对匿名**——
> 接收方掌握的外部数据、背景知识与后续发布都可能改变重识别风险。
> 全部样例为程序生成的**虚构数据**，不对应任何真实个人。

## 快速开始

零第三方依赖，仅需 Python 3.10+ 标准库。

```bash
# 启动（首次自动在 data/state.json 写入虚构种子数据）
python3 -I run.py --data data/state.json --port 8000
# 浏览器打开 http://127.0.0.1:8000/

# 测试（隔离模式）
python3 -I tests/run_tests.py
```

`-I`（隔离模式）忽略环境变量与当前目录，避免加载到外部同名模块；`run.py` 会显式把
仓库根注入 `sys.path`。

## 页面与能力

| 页面 | 能力 |
| --- | --- |
| 总览 | 关键计数、各接收方累计暴露（含已撤回）、虚构样例编排说明、审计事件 |
| 候选任务 | 候选列表、迟到任务标识、手工粘贴虚构 JSON 新建候选 |
| 发布审查 | 四预设方案比较、等价类明细（singleton / small / shrunk）、逐行差异预览、自定义层级与抑制、发布/拒发 |
| 发布账本 | 只追加账本、处置快照、撤回（必填原因）、策略版本沿革 |
| 下载中心 | 已发布制品下载；撤回立即关闭下载入口 |
| 方法与边界 | 泛化层级、信号定义、知识库口径、能力边界与"无阈值保证"声明 |

## 三类风险信号

- **singleton**：新文件内该 QI 等价类仅 1 人；
- **small**：等价类不超过策略审查线（默认 2，可调整）。审查线**只触发人工复核**，
  调高/调低都不构成匿名保证；
- **shrunk**：新组合与历史发布的粗桶相容但人数更少，明细给出具体发布 ID、时期与
  `2→1` 之类的群体变化。分桶到同粒度后若桶内成员流失（如历史 2 人、本期只有 1 人），
  信号依然成立——检测与粒度无关，只看相容桶人数变化。

## 关键设计约束（对应业务规则）

1. **累计知识库按接收方隔离**：该接收方所有发布制品的 QI 展示值并入知识库；
   **已撤回发布不删除**——撤回只停止继续下载，数据一旦发出即视为已暴露。
2. **重新发布不忘历史**：审查与发布瞬间都由服务端按**当前完整账本实时重算**，
   前端只提交处置参数，无法携带旧结论。
3. **迟到任务不能绕过新处置**：数据期早于账面最新发布期的候选标记为迟到；
   分析强制使用当前策略版本与全部历史发布。种子数据中的
   `CAND-2025H2-A-LATE` 即该场景（2025H2 补表 2026-10 才送达，账面已有 2026H1 发布）。
4. **处置同步到三处**：发布/拒发/撤回一次事务内更新候选状态、账本条目、
   汇总统计与下载入口；写操作加锁并以临时文件原子替换落盘。
5. **对外制品不含内部假名** `person_id`：它仅用于台内跨时间段 linkage 分析。
6. **策略版本单调推进**：每次发布、拒发、撤回、审查线调整都推进版本并写审计日志。

## 信息损失度量

行抑制率、泛化覆盖损失（单元覆盖值域比例）、薪资均值相对偏移、诊断分布总变差（TVD），
按固定人为权重合成综合损失与效用保留分。权重是**效用排序参数，不是隐私阈值**。

## 目录结构

```
app/
  qi.py          准标识符泛化层级与值域覆盖
  treatment.py   处置方案（抑制/分桶/拒发）与信息损失
  analysis.py    累计知识库、等价类分析、群体缩小检测、预设方案
  ledger.py      候选/账本/策略持久化（JSON + 锁 + 原子写）
  seed.py        全虚构样例（含手工编排的 2→1 稀有组合链路）
  server.py      标准库 HTTP API 与静态服务
  static/        单页前端（原生 HTML/CSS/JS）
tests/           unittest 全链路（35 个用例）
run.py           隔离模式启动器
```

## 主要 HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/stats` `/api/policy` `/api/candidates` `/api/releases` `/api/audit` | 查询 |
| GET | `/api/analysis/{candidate_id}` | 四预设方案完整分析（实时重算） |
| POST | `/api/analysis/{candidate_id}` | 自定义方案分析 `{plan}` |
| POST | `/api/publish/{candidate_id}` | 发布或拒发 `{plan}`（服务端再次重算校验） |
| PATCH | `/api/withdraw/{release_id}` | 撤回 `{reason}` |
| PATCH | `/api/policy` | 调整小群体审查线 `{small_threshold}` |
| GET | `/api/download/{release_id}` | 下载制品（撤回/拒发返回 400） |
| POST | `/api/candidates` | 上传虚构 JSON 新建候选 |

## 明确不做的事

- 不声称 k-匿名式计数或任何简单阈值能保证绝对匿名；
- 不提供差分隐私形式化保证；
- 撤回不具备消息撤回能力，无法控制已分发副本的实际流转；
- 不接入任何真实个人数据，种子与上传数据均按虚构数据处理。
